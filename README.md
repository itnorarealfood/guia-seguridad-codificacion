# Guía estándar de desarrollo seguro y escalable

Versión **1.0.0** · 16 de noviembre de 2026

Criterios prácticos para construir aplicaciones seguras, fiables y capaces de crecer. Dirigida a equipos de desarrollo y asistentes de código; independiente de producto, lenguaje y framework.

## Lectura

1. [Guía principal](GUIA.md): qué debe cumplir una aplicación y cómo comprobarlo.
2. [Checklist de entrega](CHECKLIST.md): revisión antes de integrar o publicar cambios.
3. [Instrucciones para asistentes](AGENTS.md): cómo aplicar la guía durante una tarea.
4. [Fuentes y decisiones](FUENTES.md): procedencia, versión de referencia y cambios aprobados.

## Cómo usarla

Lee la guía al comenzar un proyecto y aplica la checklist en cada entrega. Cada proyecto documenta sus tecnologías, datos, usuarios, carga prevista y decisiones de seguridad. Los controles condicionales deben justificarse cuando no apliquen.

Para un asistente de código: facilita `AGENTS.md`, `GUIA.md` y el contexto de la tarea. Esta guía establece criterios de trabajo; no concede permisos sobre sistemas, datos ni despliegues.

## Alcance

Incluye calidad del código, autenticación, permisos, validación, secretos, consistencia de datos, concurrencia, rendimiento, pruebas y entrega.

Las tecnologías concretas y la estructura del proyecto se eligen según sus necesidades. La guía se centra en los criterios de construcción y omite los detalles específicos del producto del que se ha adaptado.

## Conservación de la versión

Este repositorio se conserva **privado y archivado** para impedir cambios mientras siga archivado. Un administrador con capacidad para desarchivarlo puede volver a habilitar modificaciones: el archivo no elimina esa facultad administrativa.

Esta edición es una referencia fija. Cualquier revisión requiere una decisión explícita y una versión nueva.
